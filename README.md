# 💎 Lumière Gems & Jewels Management System

A sleek, professional Python desktop configuration engineered to automate retail pricing markups and track target profit margins across custom luxury jewelry inventory lines.

## 🚀 Key Features
* **Automated Markup Math:** Instantly computes optimal consumer retail costs based on backend inventory tier margins.
* **Dual Execution Environments:** Features both an automated command-line auditing tool and a graphical user interface desk application.
* **Typo-Resistant Validation:** Robust input validation rules prevent software runtime crashes during customer quotation entries.

## 🛠️ System Overview & Layout
The ecosystem separates underlying core financial analytics from live point-of-sale showroom desk functions to maintain operational isolation.
